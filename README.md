# Skriptjobs community

Public home for Skriptjobs support on GitHub.

The best way to reach us is here: open a discussion, request a feature, or report a bug. That keeps the thread public and searchable, so we strongly encourage it.

| Channel | Use for |
| --- | --- |
| [Discussions](https://github.com/Skriptjobs/community/discussions) | Questions, ideas, announcements |
| [Ideas](https://github.com/Skriptjobs/community/discussions/new?category=ideas) | Feature requests |
| [Issues](https://github.com/Skriptjobs/community/issues) | Bug reports (use the Bug template) |

You can also email [support@skriptjobs.com](mailto:support@skriptjobs.com).

**Support call hours:** 8:00–18:00, Monday–Friday, Central European Time. Same hours as [Contact](https://skriptjobs.com/contact).

Product source code lives in a private repository. This repo is for the community only.

Website: [skriptjobs.com](https://skriptjobs.com)
